L Systems

Explanation

L systems carry out simple character to string replacements.

You begin with a string (called the axiom) and then loop though each character in the string. Each character is then replaced by a string based on some rules. This process is repeated however many times you would like, usually called the number of iterations or the depth.

Example

Rules

Character String
A AB
B A

Iterations

In the following example I have used the ^ character to show the current character the algorithm is looking at.

Start

The first string also known as the axiom will be “A” for this example.

A
^
Iteration 1

Change A to AB and move to next character.

AB
  ^

This iteration has ended since we have reached the end of the string.

Iteration 2

Start at the beginning of the last iteration’s string.

AB
^

A must be replaced with AB, then move on to the next character.

ABB
  ^

B must be replaced with A, then move on to the next character.

ABA
   ^

We have reached the end of the string meaning this iteration is over.

Example review

This L system can be used to model the growth of algae and was the original L system that Aristid Lindenmayer made. With L systems you can theoretically choose any number of iterations you would like to do. However the string will never shrink in size, meaning that due to memory constraints the number of iterations is limited.

Uses

L systems have a fractal nature making them great for generating fractal graphics. In this case each character can also have an action such as “move forwards” or “turn left”, then a program can carry out these instruction to draw the fractal. This way of drawing graphics is called turtle graphics.

2D L system

I started with a 2D L system generator.

F -> FF+[+F-F-F]-[-F+F+F]
* -> *
(where * matches any character)

where the characters have the following actions:

Character Action
F Move forwards
+ Turn left 25°
- Turn right 25°
[ Save current position
] Return to last saved position

I also have an array of colours so that when the save character is read it changes to the next colour, and when the load character is read it changes to the previous colour. This wasn’t necessary but I thought it looked cool.

3D L system

I wanted to make an L system which was 3D, and after some playing around I found the following configuration.

I added two more instructions to rotate along a different axis.

Character Action
F Move forwards
+ Turn left 20°
- Turn right 20°
9 Turn left 20° about the y axis
0 Turn right 20° about the y axis
[ Save current position
] Return to last saved position

Then I changed the rules to this:

F -> FF+0[+F-F-F9]-0[-F+9F+F]
* -> *

This generated this 3D fractal plant thing, which I am very pleased with:

It looks fairly realistic in 3D. Especially after making the lines transparent and the background white, because this made more dense areas darker.
