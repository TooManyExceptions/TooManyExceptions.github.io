Ray Marching

Explanation

Ray marching is a rendering technique which sends rays out from the camera, and marches each ray forwards until the ray is close enough to an object in the scene.

The 3D scene is defined using a function which returns the minimum distance from the closest object to a given 3D point. This is called the signed distance function.

You can find lots of signed distance functions for simple 3D shapes the website made by Inigo Quilez.

Each ray from the camera is marched the distance returned by the signed distance function, until the signed distance function gives a low enough distance for it to be counted as being on the surface. By only marching the minimum distance this algorithm is guaranteed to not overshoot the object.

Raymarching
A way to render a 3D scene
Uses a signed distance function to define the scene with objects such as:
  • Spheres
  • Cubes
  • Fractals
  • Tetrahedrons
Signed distance function
A function which returns the minimum distance from a surface in the scene
  • Positive outside the object
  • Zero on the surface of the object
  • Negative inside the object
The signed distance function of multiple objects is just the minimum distance between the objects
  • Calculate the distance away from each object
  • Return the shortest out of those distances

Raymarching has some advantages over other forms of rendering because the space can be transformed more easily. For example by taking the modulus of the position into the signed distance function in the right way, you can repeat an object. This means you can have objects seemingly repeat forever, without much of a performance penalty. You can also do reflections and scaling, allowing you to render 3D fractals like the Sierpiński tetrahedron.

Raymarcher with basic lighting

Next I wanted to add lighting to the raymarcher.

This lighting uses the direction of the face of an object and compares it to the direction of a global light source to find how bright the surface should appear.

To do this I calculate the normal vector to the surface, once a ray hits the surface of an object by doing the derivative of the signed distance function. Giving the direction of the face the ray landed on. Then I do the dot product between the light direction and the normal vector, to basically get how much the face is pointing in the direction of the light. Then colour it based on that.

This picture also shows how you can easily add and subtract objects from each other. This is using the maximum of two minimum distances from the two shapes (cube and sphere in this case) with the distance to the shape you want to be subtracted as a negative number. You can even combine shapes in a smooth way leading to the shapes kind of melding into each other.
